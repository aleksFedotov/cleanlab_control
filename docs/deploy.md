# Деплой CleanLab Control (Прачка360) — чек-лист

Выполняется вручную владельцем проекта. Порядок важен.

## 1. Проект GAS и таблица

1. `npm i -g @google/clasp` (один раз), `clasp login` — войти в Google-аккаунт прачечной.
2. Создать новую Google Таблицу (напр. «Прачка360 БД»).
3. В таблице: Расширения → Apps Script → создать проект. Скопировать **Script ID** (Настройки проекта → ID скрипта).
4. Вставить Script ID в `.clasp.json` вместо `PASTE_SCRIPT_ID_HERE`.
5. Часовой пояс: в настройках проекта GAS и в свойствах таблицы (Файл → Настройки) выставить **(GMT+03:00) Москва**. В `appsscript.json` уже стоит `Europe/Moscow`.
6. `clasp push` — залить код из `src/`.

## 2. Секреты — Script Properties

В редакторе GAS: Настройки проекта → Свойства скрипта. Добавить:

| Свойство | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `OWNER_PIN` | PIN владельца (напр. 4–6 цифр) |
| `WORKER_PIN` | PIN сотрудника (другой!) |
| `WEBHOOK_SECRET` | случайная строка (напр. 32 символа) |
| `TV_KEY` | случайная строка для табло |
| `OWNER_CHAT_ID` | не заполнять — запишет бот на шаге 6 |

## 3. Инициализация БД

В редакторе GAS запустить функцию `setup()` (выполнить вручную, принять запрос разрешений). Создаются 7 листов, заголовки, стартовые типы белья, `Settings` (`SCHEMA_VERSION=1`). Повторный запуск безопасен (идемпотентна).

## 4. Деплой веб-приложения

1. Редактор GAS → Начать развёртывание → Веб-приложение.
2. Execute as: **Me**; Who has access: **Anyone**.
3. Скопировать URL веб-приложения (`.../exec`).
4. В таблице на листе `Settings` записать `WEB_APP_URL` = этот URL.
5. **При каждом изменении кода**: `clasp push` → Развёртывания → Управление → новая версия (без новой версии изменения не применятся).

## 5. Telegram

1. Создать бота у @BotFather, токен → `BOT_TOKEN` (шаг 2).
2. Установить webhook (подставить токен, URL и секрет):
   ```bash
   curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<WEB_APP_URL>?secret=<WEBHOOK_SECRET>"
   ```
3. В Telegram написать боту: `/start <OWNER_PIN>` → ответ «дайджесты подключены ✓» (записывается `OWNER_CHAT_ID`).

## 6. Триггеры

В редакторе GAS запустить `installTriggers()` — создаются: fallback-дайджест ежедневно на `DIGEST_TIME` (из `Settings`, по умолчанию 21:30) и бэкап ночью. Повторный запуск безопасен (старые триггеры снимаются).

## 7. Табло цеха

Ссылка: `<WEB_APP_URL>?tv=1&key=<TV_KEY>` (держать в секрете — это единственная защита табло).

Железо (два варианта):
- **Вариант A — ТВ-приставка/Смарт-ТВ**: открыть ссылку в браузере ТВ, вывести на весь экран. Плюс: большой экран; минус: нужна приставка.
- **Вариант B — старый планшет/ноут на стене**: открыть ссылку, закрепить вкладку, отключить блокировку экрана. Плюс: бесплатно из имеющегося; минус: меньше экран.

В обоих: страница сама обновляется каждые 45 сек, при потере связи показывает последние данные с красной плашкой.

## 8. Планшет сотрудника

Открыть `<WEB_APP_URL>`, войти по `WORKER_PIN`, добавить на главный экран. Владелец заходит по `OWNER_PIN` с телефона/компьютера.

## 9. Проверка после деплоя

1. Владелец: Справочники → добавить клиента.
2. Развоз: «+ В развоз» на завтра.
3. Сотрудник (вкладка «Цех», дата завтра): «В работу» → вес → пересчёт → «Завершить».
4. «Закрыть смену» → владельцу в Telegram приходит дайджест.
5. Табло: счётчики и карточка стирки видны.
6. На Drive: папка `Прачка360/backups` появится после первого ночного бэкапа.

## Локальная разработка

- Тесты: `npm test` (Node, без GAS — чистое ядро + API на моках).
- Перед `clasp push` убедиться, что тесты зелёные.
