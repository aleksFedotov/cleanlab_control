# Дизайн-спецификация «Чистая вода» — дашборд прачечной

> **Назначение файла.** Это задание для Kimi Code: реализовать этот дизайн при переносе фронтенда прачечной с `server/public/index.html` на Next.js (App Router, клиентский SPA, `'use client'`). Архитектура, структура папок и этапы описаны в `nextjs-migration.md` — этот файл дополняет его визуальной частью. **Бизнес-логика, API-контракт и состав данных не меняются** — меняется только оформление.
>
> **Характер дизайна:** светлый, спокойный, аккуратный. Фирменный синий `#2563eb` — единственный яркий акцент; всё остальное — нейтральная серая шкала + мягкие пастельные статусы. Много воздуха, карточки вместо таблиц где возможно, ничего лишнего.

---

## 1. Дизайн-токены (`globals.css`)

Все значения задаются CSS-переменными в `:root` и используются только через них. В Tailwind-проекте продублировать в `tailwind.config`.

### Цвета

```css
:root {
  /* Акцент (фирменный синий) */
  --bluing: #2563eb;        /* кнопки, активные состояния, ссылки */
  --bluing-hover: #1d4ed8;
  --bluing-soft: #eff6ff;   /* фон активного пункта меню, time-чипов */
  --bluing-soft-2: #dbeafe; /* бейдж «в стирке» */
  --bluing-border: #bfdbfe; /* рамка ghost-кнопок */

  /* Нейтрали */
  --bg: #f8fafc;            /* фон контентной области */
  --surface: #ffffff;       /* карточки, сайдбар, хедер */
  --border: #e2e8f0;        /* все рамки */
  --text: #0f172a;          /* основной текст */
  --text-2: #475569;        /* вторичный текст, неактивные пункты меню */
  --text-3: #64748b;        /* подписи в карточках */
  --text-4: #94a3b8;        /* заглушки, верхние метки StatCard */

  /* Статусы (текст / фон бейджа) */
  --ok: #16a34a;        --ok-bg: #dcfce7;   /* готово */
  --wash: #1d4ed8;      --wash-bg: #dbeafe; /* в стирке */
  --warn: #d97706;      --warn-bg: #fef3c7; /* внимание / не готово */
  --late: #b91c1c;      --late-bg: #fee2e2; /* просрочено */
  --neutral: #475569;   --neutral-bg: #f1f5f9; /* очередь / новое */

  /* Опасное действие */
  --danger: #dc2626;    --danger-hover: #b91c1c;
}
```

### Формы, тени, отступы

```css
:root {
  --radius-s: 8px;    /* кнопки, чипы, инпуты */
  --radius-m: 10px;   /* пункты меню, time-чипы */
  --radius-l: 14px;   /* карточки, StatCard, карточки визитов */
  --radius-xl: 20px;  /* крупные панели, модалки */
  --radius-pill: 999px; /* бейджи, FilterPills, аватары */

  --shadow-card: 0 1px 2px rgba(15,23,42,.05);
  --shadow-pop: 0 16px 40px rgba(15,23,42,.12);  /* модалки, дропдауны */

  --gap: 14px;        /* шаг сетки карточек */
  --content-max: 1100px;
}
```

Тени — только мягкие и почти незаметные. Никаких жёстких/цветных теней на карточках.

### Типографика

- **Inter** — весь интерфейс; **JetBrains Mono** — время, даты в таблицах, номера, килограммы в монospace-блоках (time-чипы визитов).
- Подключение: `next/font/google` в корневом `layout.jsx` (`Inter`, `JetBrains_Mono`, переменные `--font-sans` / `--font-mono`).
- Шкала: заголовок страницы 18–20px/800, заголовки внутри карточек 14–15px/700, основной текст 13.5–14px, вторичный 12.5px, метки StatCard 12px/600 uppercase + letter-spacing 0.6px.
- Числа в StatCard: 28px/800, `letter-spacing: -0.8px`, `font-variant-numeric: tabular-nums` (везде, где цифры обновляются).

## 2. Карта статусов (`lib/dicts.js`)

Единственный источник правды для цветов и подписей. Компонент `StatusBadge` берёт отсюда всё:

| Ключ | Подпись | Текст | Фон | Где |
|---|---|---|---|---|
| `new` | Очередь | `--neutral` | `--neutral-bg` | стирка не начата |
| `wash` | В стирке | `--wash` | `--wash-bg` | идёт стирка |
| `ready` | Готово | `--ok` | `--ok-bg` | готово к выдаче |
| `issued` | Выдано | `--neutral` | `--neutral-bg` (50% opacity у карточки) | завершено |
| `late` | Просрочено | `--late` | `--late-bg` | перекрывает текущий статус, если время выдачи прошло |

Роли: `owner` → «Владелец», `worker` → «Работник», `driver` → «Водитель».

## 3. UI-кит (`components/ui/`)

Все компоненты — до переноса страниц. Страницы собираются только из них.

### Button
Варианты: `primary` (синяя заливка `--bluing`, hover `--bluing-hover`, белый текст, radius-s, padding 10px 16px, 14px/700), `ghost` (белый фон, рамка `--bluing-border`, текст `--bluing`), `danger` (красная заливка), `subtle` (без рамки, текст `--text-2`, hover — фон `--neutral-bg`). Пропсы: `busy` (спиннер + disabled), `icon`, `size: sm|md`.

### Card
Белый фон, рамка `1px --border`, `radius-l`, `shadow-card`, padding 16–18px. Без hover-эффектов по умолчанию; интерактивные карточки (кликабельные) — `hover: border-color: var(--bluing-border)` + translateY(-1px).

### StatCard / StatRow
StatRow — grid из 3–4 StatCard с `gap: var(--gap)`. StatCard: верхняя метка (12px uppercase, `--text-4`), значение (28px/800, tabular-nums, может иметь цветовой модификатор `tone: ok|warn|late|default`), подпись снизу (12px, `--text-3`, может быть цветной). Единицы («кг») — 15px `--text-4` рядом со значением, не в отдельной строке.

### StatusBadge
Pill (radius-pill), 11.5px/700, padding 5px 11px, цвета только из словаря статусов. `white-space: nowrap`.

### FilterPills
Горизонтальный ряд кнопок-pill: неактивная — белый фон, рамка `--border`, текст `--text-2`; активная — заливка `--bluing`, белый текст. В подписи всегда счётчик: «Готовы · 7». Скроллятся горизонтально на узких экранах.

### DateNav
`‹` + «21 августа 2026» + `›` + кнопка «Сегодня». Стрелки — квадратные 28×28 с рамкой `--border`, radius-s. Дата — 13.5px/600. Кнопка «Сегодня»: фон `--bluing-soft`, текст `--bluing`, без рамки; скрыта/disabled, если выбран текущий день. Формат даты — из `lib/dates.js` (`formatDateRu`).

### DataTable
Для Склада, Отчёта, Справочников, Сотрудников, Прачек. Шапка: 12px uppercase `--text-4`, нижняя граница `--border`. Строки: высота 52px, разделители `--border` (без вертикальных линий и «зебры»), hover-строка — фон `--bg`. Числа и время — JetBrains Mono, tabular-nums, выравнивание вправо. Раскрытие строки (в Отчёте) — плавное, иконка-шеврон поворачивается.

### Modal / ConfirmDialog
Оверлей `rgba(15,23,42,.4)` + blur 4px. Панель: белая, `radius-xl`, `shadow-pop`, max-width 480px, заголовок 17px/800. ConfirmDialog — два действия: основное (danger, если удаление) + subtle «Отмена». Закрытие по Esc и клику на оверлей.

### Toast
Правый нижний угол, стек до 3 шт. Белая карточка с цветной полосой слева 3px (ok — зелёная, ошибка — красная), 14px, автоскрытие 4с. Ошибки API показывать текстом сервера, не «Что-то пошло не так».

### Empty
Центрированный блок: иконка 40px в круге `--neutral-bg`, заголовок 15px/700, подпись 13px `--text-3`, опционально кнопка-действие («Добавить первого клиента»). Использовать вместо пустых таблиц/списков.

### PageHeader
Заголовок страницы + (справа) основное действие («+ Добавить»). На страницах с датой — в хедере layout'а, не дублировать.

## 4. Каркас дашборда

### Layout (владелец, ≥1024px)

```
Сайдбар 240px | Хедер | Контент (max-width 1100px, padding 24–28px)
```

- **Сайдбар** (240px, белый, правая граница `--border`): логотип (иконка 34px, градиент `#2563eb → #60a5fa`, radius 10px + название «Прачка» и подпись «панель владельца» 11px `--text-4`). Пункты: иконка 17px + текст 13.5px, radius-m, padding 9px 12px. **Активный пункт**: фон `--bluing-soft`, текст `--bluing`, 600. Порядок: Сегодня (с бейджем-счётчиком визитов — синий pill с белым числом), Стирка, План, Склад, Отчёт — разделитель `1px --border` — Справочники, Сотрудники, Прачки. Внизу — «Выход» (`--text-4`). Сворачивается до 64px (только иконки, тултипы), состояние — localStorage.
- **Хедер** (белый, нижняя граница `--border`, padding 14px 28px): заголовок раздела 18px/800 → DateNav (на страницах с датой) → справа: переключатель прачки (`ghost`-селект, если прачек >1) + аватар 32px (синий круг, инициал) с дропдауном (профиль, выход).
- **Мобильно** (<1024px): сайдбар → выдвижная панель поверх (оверлей), гамбургер в хедере. Контент — одна колонка, StatRow → 2×2.

### Иконки
`lucide-react` — единственный набор иконок в дашборде. Сегодня — `clock`, Стирка — `waves`/`list`, План — `calendar`, Склад — `package`, Отчёт — `bar-chart-3`, Справочники — `book-open`, Сотрудники — `users`, Прачки — `building-2`, Выход — `log-out`.

## 5. Страницы (все `'use client'`, данные — через `lib/api.js` + `useApi`)

### Сегодня (`today`)
1. StatRow: **Визитов сегодня** (подпись: «4 утром · 8 днём»), **Готовы к выдаче** (tone ok, подпись «+N за час»), **Не готовы** (tone warn, подпись «N в стирке · N в очереди»), **Вес в работе** (кг + подпись «N мешков»).
2. FilterPills: Все / Готовы / В стирке / Очередь / Просрочены — со счётчиками.
3. Карточки визитов — сетка 2 колонки (1 на мобильном). Карточка: слева **time-чип** (JetBrains Mono 13px/700, `--bluing` на фоне `--bluing-soft`, radius-m, время в две строки «09:00 / –10:00»), затем название клиента 14px/700 + строка деталей 12.5px `--text-3` («постельное · 18 кг · 3 мешка»), справа StatusBadge. Просроченный визит — дополнительно тонкая красная левая кромка 3px у карточки.

### Стирка (`wash` + `wash/[id]`)
- Переключатель вида «доска / список» (иконки, состояние в localStorage).
- Доска: колонки по статусам (Очередь / В стирке / Готово / Выдано), заголовок колонки — StatusBadge + счётчик. Карточка стирки: клиент, состав, кг/мешки, время, StatusBadge. Клик → страница стирки.
- Карточка стирки `[id]`: PageHeader с клиентом и StatusBadge; блоки «Состав», «История статусов» (вертикальный таймлайн: точка цвета статуса + подпись + время в mono), действия — Button'ы по допустимым переходам статуса.

### План (`plan`)
Недельная сетка: 7 колонок-дней (понедельник первым), сегодняшний день подсвечен фоном `--bluing-soft`. Ячейка дня — карточки визитов урезанного вида (время mono + клиент + StatusBadge). Шапка — DateNav в режиме недели («‹ 17–23 августа ›»).

### Склад (`storage`)
StatRow (позиций, заканчивается — tone warn, под нулём — tone late) + FilterPills по категориям + DataTable: Наименование / Категория / Остаток (mono, вправо; меньше порога — значение цвета `--warn` + бейдж «Заканчивается») / Действия (icon-кнопки subtle).

### Отчёт (`report`)
DateNav + StatRow (визиты, кг, мешки, средний вес) + FilterPills (по прачке/клиенту/статусу) + DataTable с раскрытием строки (детали визита). Числа mono, вправо.

### Справочники / Сотрудники / Прачки (`refs`, `users`, `laundries`)
PageHeader + кнопка «+ Добавить» (primary). DataTable; действия в строке — icon-кнопки subtle (редактировать `pencil`, удалить `trash-2` → ConfirmDialog danger). Сотрудники: колонка «Роль» — StatusBadge из словаря ролей (нейтральные цвета). Пустые состояния — Empty с кнопкой.

### Логин (`login`)
Центр экрана: карточка 380px, `radius-xl`, `shadow-pop`. Логотип сверху, заголовок «Вход в Прачку». PIN — 4–6 отдельных квадратных инпутов (mono, 24px, radius-s, автофокус-переход); или логин+пароль — инпуты с рамкой `--border`, фокус — рамка `--bluing` + мягкое свечение `--bluing-soft`. Кнопка «Войти» — primary на всю ширину. Ошибка — красный текст 12.5px под формой + лёгкая тряска карточки.

## 6. Мобильные экраны работника и водителя (`worker`, `driver`)

Отдельный layout без сайдбара: одна колонка, нижняя навигация, крупные цели нажатия (кнопки ≥48px, radius 12px).

### Общее
- Шапка: строка контекста 12px `--text-4` («Смена · Центральная» / «Маршрут · 21 августа»), приветствие 19px/800 («Анна, доброе утро»), три мини-статистики в ряд (карточки `--bg`, значение 20px/800 цветное + метка 10.5px `--text-4`).
- Нижняя навигация: белая, верхняя граница `--border`, 3 пункта (иконка 19px + подпись 10.5px). Активный — `--bluing`.
- Секции помечены метками 11px/700 uppercase letter-spacing 1px `--text-4`.

### Работник
Навигация: Задачи / Склад / Профиль.
- «Сейчас в работе»: карточка активной стирки — клиент + StatusBadge, детали (состав, кг, машина №, режим, время начала), большая кнопка primary **«✓ Завершить стирку»** на всю ширину.
- «Дальше по очереди»: карточки с кнопкой ghost **«Начать стирку»**.

### Водитель
Навигация: Маршрут / История / Профиль.
- «Следующий адрес»: выделенная карточка — клиент + pill с окном времени, адрес, мешки/кг, контакт с телефоном (tappable `tel:`). Кнопка primary **«🚚 Доставлено»**, под ней ghost **«Построить маршрут»**.
- «Далее»: компактные карточки остальных адресов.

## 7. Состояния (обязательно для каждой страницы)

- **Загрузка:** скелетоны, повторяющие раскладку (серые блоки `--neutral-bg` с shimmer), без спиннеров на весь экран.
- **Ошибка API:** Toast с текстом ошибки + кнопка «Повторить» на месте контента, если данных нет вообще.
- **Пусто:** Empty, не пустая таблица.
- **Offline:** тонкая полоса сверху «Нет соединения, данные могут быть неактуальны» (`--warn-bg`), обработка в `lib/api.js`.
- **Busy на кнопках** при мутациях; двойная отправка исключена.

## 8. Что НЕ делать

- Не вводить вторую акцентную палитру, градиенты на фонах, glassmorphism, анимации «ради анимаций».
- Не менять API-контракт (`POST /api/<method>` `{args: [...]}`), состав полей, бизнес-правила статусов — это чисто визуальный перенос.
- Не использовать эмодзи как иконки в дашборде владельца (только lucide). В мобильных экранах работника/водителя допустимы эмодзи в кнопках-действиях (✓, 🚚) — это осознанное упрощение.
- Никаких локальных перекрасок статусов вне `lib/dicts.js`.

## 9. Критерий приёмки дизайна

Открываешь любую страницу — и: только один яркий цвет на экране (синий акцент + пастельные статусы); все статусы выглядят одинаково везде; цифры не «прыгают» при обновлении (tabular-nums); на телефоне дашборд владельца и экраны работника/водителя удобны без горизонтального скролла.
